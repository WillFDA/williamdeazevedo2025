# Brouillon LinkedIn personnel — 1er octobre 2026

Changer de prestataire web ne signifie pas forcément transférer son nom de domaine.

Avant une reprise, il vaut mieux distinguer plusieurs choses qui sont souvent regroupées dans un même contrat : le registrar du domaine, les DNS, l’hébergement, le CMS, les fichiers du site et la messagerie.

Exemple concret à vérifier dans votre organisation : le site peut être hébergé chez un fournisseur, le domaine géré chez un autre et les e-mails configurés dans un troisième compte. Si les DNS sont modifiés avant que la nouvelle zone soit prête, le site ou la messagerie peut cesser de répondre.

L’ordre utile : inventorier les accès, sauvegarder les éléments nécessaires, tester la restauration, préparer la nouvelle version, planifier séparément le site et les e-mails, puis retirer les anciens accès après validation. Pour un domaine en .fr, l’Afnic décrit une procédure de transfert de bureau d’enregistrement distincte d’un changement d’hébergement ; les règles varient selon l’extension.

J’ai préparé une checklist pour organiser cette passation sans supposer que tout doit être transféré ni promettre une migration sans interruption.
